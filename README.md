# Каталог экзопланет и генератор промптов для нейросетей

Полноценное веб-приложение для каталогизации, визуализации и анализа экзопланет. Система включает бэкенд на FastAPI, фронтенд на Streamlit, базу данных MySQL и собственный астрофизический классификатор, который динамически генерирует промпты для нейросетей на основе реальных физических параметров планет и звёзд.

---

##  Обзор

Проект разработан как учебная курсовая работа для демонстрации навыков проектирования баз данных, разработки REST API и создания интерактивных веб-интерфейсов. Приложение обрабатывает реальные данные из архива NASA Exoplanet Archive, классифицирует типы планет по массе/радиусу/плотности, визуализирует родительские звёзды по спектральному классу и предоставляет административные инструменты для управления каталогом.

---

## Возможности

###  Аутентификация и роли
- Регистрация пользователей с валидацией email и имени
- Управление сессиями (учебное хранение паролей в открытом виде)
- Разделение прав доступа: `user` / `admin`

### Каталог планет
- Пагинация по 20 записей на страницу
- Полнотекстовый поиск по названию планеты
- Сортировка по: заполненности данных, массе, радиусу, температуре, расстоянию
- Применение фильтров с сохранением состояния страницы

### Детальный просмотр планеты
- Полные параметры, сгруппированные по категориям:
  - **Орбитальные:** период, большая полуось, эксцентриситет, наклонение
  - **Физические:** радиус, масса (мин. и точная), плотность, равновесная температура, инсоляция
  - **Транзитные:** глубина, длительность, параметр удара
  - **Открытие:** метод, год, флаг контроверсиальности, расстояние
- **Данные звезды:** спектральный тип, температура, радиус, масса, металличность, светимость, возраст, координаты
- **Визуализация:** сфера планеты + сфера звезды, цвета определяются автоматически
- **Генерация промптов:** динамические запросы на русском и английском для нейросетей
- **Галерея изображений:** заглушка для будущей интеграции с генеративными моделями

### Администрирование
- Создание, редактирование и мягкое удаление (soft delete) планет прямо из карточки
- Формы с валидацией всех полей таблицы
- Soft delete (`is_deleted = TRUE`) сохраняет целостность данных
- Админ-интерфейс встроен в основной поток приложения

###  Интерфейс
- Тёмная тема, оптимизированная для работы с астрономическими данными
- Красивая вёрстка, с карточками, подстраивающимся под их содержимое (цвет звезды и планеты)
- Адаптивная сетка карточек с эффектами наведения
- Кастомный CSS для метрик, полей ввода, кнопок и уведомлений
- Нативное управление состоянием и маршрутизация Streamlit

## Стек технологий

| Компонент | Технология |
|-----------|------------|
| **Фронтенд** | Streamlit, Custom CSS |
| **Бэкенд** | FastAPI, Uvicorn |
| **База данных** | MySQL 8.0, `mysql-connector-python` |
| **Обработка данных** | Pandas (импорт CSV), Кастомный классификатор |
| **HTTP-клиент** | `requests` |
| **Валидация** | Pydantic, Regex, Streamlit Forms |
| **Развёртывание** | Локальная разработка (`uvicorn` + `streamlit`) |
